# Ahmad Almohamad Almossa — Portfolio

This is a static portfolio website for GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `ahmad-portfolio`.
2. Upload `index.html` and `Ahmad_Almohamad_Almossa_IT_Portfolio.pdf`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. GitHub will provide a public URL for the portfolio.

## Before publishing
Replace:
- `YOUR_EMAIL@example.com` with your real email.
- `https://www.linkedin.com/` with your LinkedIn profile.
- `https://github.com/` with your GitHub profile.

The site is intentionally static, fast and suitable for recruitment/Talent Pool links.
